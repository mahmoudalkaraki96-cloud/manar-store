# تعليمات وكلاء المشروع

- اقرأ HANDOFF.md وTASKS.md قبل العمل، وافحص الحالة الحالية قبل الاعتماد على القديم.
- تعامل بالعربية الواضحة مع محمود. اذكر المنجز الفعلي والعوائق، لا تدّع التكامل لمجرد وجود واجهة.
- المستخدم يشترط شرح أي تنفيذ خارجي وانتظار موافقته؛ تفويضه الصريح المحدد يستمر لنفس الإجراء. يمكنك القراءة والفحص وتجهيز العمل محليًا. لا تفعّل ردودًا أو تنفق إعلانات دون تفويض.
- حدّث HANDOFF.md وTASKS.md في نفس commit مع التغيير: التاريخ، المنجز، الاختبارات، العوائق، الخطوة التالية. لا تسجل أسرارًا أو محادثات أو بيانات زبائن.
- عند بدء العمل على جهاز آخر: افحص git status، ثم اجلب آخر الفرع. لا تستبدل تغييرات محلية أو تستخدم force push.
- المدير والبوابة مستقلان عن المتجر. لا تنشر عبر wrangler المتجر من جذر المستودع. لا تتعامل مع بياناته أو تغيّر النشر لمجرد إضافة هذا المجلد.
- أي push إلى main قد يشغل نشر المتجر. استخدم فرعًا خاصًا للمدير وPR حتى تُراجع الآثار.
- manager/ مصدر Site قائم؛ .openai/hosting.json يحفظ هويته. الأسرار والبيانات الفعلية في الاستضافة، ليست في هذه النسخة. لا تنشئ Site أو قاعدة بديلة بدون حاجة وموافقة.
- gateway/ بوابة استقبال فقط. احفظ التوكنات كأسرار، أرسل Sites token إلى الوجهة الثابتة فقط، لا تتبع redirect به.
- نفّذ اختبارات مناسبة ثم سجل النتائج. الربط غير مكتمل حتى تصل رسالة اختبار فعلية وتظهر في الصندوق.
