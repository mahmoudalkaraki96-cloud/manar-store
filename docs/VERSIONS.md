- قبل التنفيذ يُشرح التعديل ورقم نسخته للمستخدم ويُنتظر إذنه؛ الطلب الصريح بالتنفيذ إذن للتعديل المحدد.
- تُسجل النسخة وملخصها وcommit الكود ورابط النشر وحالة الفحص. لا تُعلن منشورة قبل نجاح النشر.
- تعديلات التوثيق وحدها لا تغيّر رقم نسخة الموقع ولا تحتاج نشرًا جديدًا. لا يُضاف رقم ظاهر للزبائن إلا بطلب.
- التراجع يُسجّل كإصدار مستقل مع توضيح النسخة/commit المستعاد، دون حذف تاريخ الإصدارات.
