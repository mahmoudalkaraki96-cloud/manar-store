## الجمع

شغّل Start-RokonImport.ps1 للسلطان أولًا. ينقل ملفات التشغيل والمكتبات إلى H:\RokonImport ويفتح Chrome الموجود على جهازك؛ لا يحمّل متصفحًا جديدًا. جلسة Chrome هذه مستقلة عن المتصفح داخل المحادثة، ولذلك تسجّل الدخول فيها بنفسك مرة واحدة. لا تُقرأ أو تُنسخ كلمات المرور أو كوكيز المتصفح الحالي. بعد الدخول اضغط Enter في نافذة PowerShell.

```powershell
& 'C:\Users\MahmoudKaraki\Documents\ChatGPT\موقع منار بارتي\outputs\rokon-import\Start-RokonImport.ps1' -Source sultan
```

للبازار استبدل sultan بـ bazar. أكد المالك أن البازار لا يحتوي تسجيل دخول؛ يبدأ جمع الأسعار العامة مباشرة، ويستخدم الصفحة نفسها لسعر قبل/بعد الخصم دون طلبين مكررين. السلطان وحده يشترط تسجيل الدخول. المورد الثالث يُضاف بعد تزويد رابطه.

ينفذ طلب GET واحدًا كل مرة مع انتظار عشوائي 3–5 ثوانٍ، ويجمع روابط الصفحات الفعلية ويمنع تكرارها. يقرأ نسخة حسابك ونسخة عامة لكل منتج، ويطابق الخيارات بمعرفاتها وأسمائها حتى لا يخلط أسعار المقاسات. يتوقف عند403/429 أو انتهاء الجلسة/تحدي حماية، ولا يتحايل على الحظر أو يعيد المحاولة تلقائيًا.

يحفظ التقدم في ملف checkpoint مستقل لكل مصدر داخل H:\RokonImport\data بعد كل صفحة ومنتج، بدون كوكيز أو كلمات مرور. عند تشغيله مجددًا تستعيد نافذة Chrome الجديدة هذا التقدم وتكمل بعد تسجيل الدخول، حتى لو أغلقت النافذة السابقة. ينزّل JSON نهائيًا أو جزئيًا عند التوقف، وزر «إيقاف وحفظ الملف» يحفظ ما تم. لا تمسح ملفات النتائج. لجولة تحديث جديدة مقصودة بعد إكمال الجولة القديمة يمكن تشغيل `node .\run-collector.mjs sultan --fresh`؛ لا تستخدم fresh أثناء حظر الموقع.

## البيانات والتسعير

- الاسم، جميع تركيبات اللون/المقاس ومعرفاتها، صور الخيارات والصور العامة، الوصف والمواصفات والملاحظات وحقول التخصيص المدعومة وروابط الفيديو.
- الشراء من سعر الحساب، والبيع من السعر قبل الخصم من الصفحة العامة للخيار نفسه. عند تساويهما: زيادة20% وتقريب إلى الشيكل الأعلى باستخدام حساب صحيح بالأغورات. مثال12₪ يصبح15₪، و15₪ يصبح18₪. سعر أقل من التكلفة/سعر غير محدد/بنية خيار غير معروفة يذهب للمراجعة.
- المنتجات غير المتاحة لا تُستورد. الخيار المتاح رصيده100؛ غير المتاح محفوظ بالبيانات وبرصيد0 وغير نشط. جميع المنتجات المستوردة مسودات.
- اسم المورد ورابطه ورقم المنتج وسعره محفوظة في product_suppliers، ولقطة كاملة للمصدر في rokon_supplier_imports؛ لا تُكتب عبارة «تم الاستيراد» في مواصفات الزبون.
- الحقول التي لا تدعمها اللوحة مثل رفع الملفات/قائمة تخصيص/حد أدنى أكبر من1 لا تُحذف بصمت؛ يتوقف استيراد المنتج للمراجعة. فحص التوفر يعتمد إشارات HTML للمصدر؛ أي تغيير في تصميمه يحتاج مراجعة المحلل.

## تطبيق لاحق على ركن فقط

التطبيق يحتاج معرف حساب Cloudflare ومعرف قاعدة ركن، وتوكن D1/Workers للقراءة والتحقق وD1 للكتابة في متغير البيئة CLOUDFLARE_API_TOKEN، وWrangler مسجل الدخول لرفع صور R2، ومكتبة Pillow (`python -m pip install Pillow`). لا تضع توكنًا في الملف أو المحادثة.

```powershell
python .\rokon_import.py .\data\اسم-الملف.json --output .\report.json --apply --account-id ACCOUNT_ID --database-id ROKON_DATABASE_ID
```

قبل أي كتابة يتحقق من اسم القاعدة rokon-store-db ومن ربط واجهة ولوحة ركن بنفس القاعدة وrokon-store-media. لا يوجد معرف قاعدة منار أو Red Rose في السكربت. ينسخ الصور والفيديوهات إلى R2 ركن؛ يحفظ صور WebP ومصغرات384px بالمفاتيح المعتمدة. يمكن لـWrangler وCloudflare استهلاك حصصهما المعتادة، لكن لا توجد خدمة AI مدفوعة.

لكل منتج دفعة D1 واحدة تربط الصنف والمتغيرات وأسعار شرائها وصورها ومصدرها وسجل إكماله. إعادة التنفيذ تتجاوز السجل المكتمل؛ لا تعدّل أصنافًا قديمة ولا تنشر المسودات. عند تعارض اسم slug أو نقص مورد/قسم يتحقق ويتوقف. الأقسام الجديدة غير نشطة حتى تراجعها. لن تُطبق لقطة جمع غير مكتملة. API batch موثق في [Cloudflare D1](https://developers.cloudflare.com/api/resources/d1/subresources/database/methods/query/).
